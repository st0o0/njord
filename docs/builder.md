# Config Builder

Build your njord configuration interactively. Add locations (name, latitude and longitude are required), choose the enrichments you want (the fetched domains follow from them), see the budget impact in real-time, then copy the result as `appsettings.json`, environment variables or a `docker-compose.yml`.

You can also import an existing config to edit it, or share your configuration via the URL.
