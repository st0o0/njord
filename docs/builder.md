# Config Builder

Build your njord configuration interactively. Add locations (name, latitude and longitude are required), choose the features you want, grouped by category (the fetched domains follow from them, and each feature shows the API calls per day it adds), see the budget impact in real-time, then copy the result as `appsettings.json`, environment variables or a `docker-compose.yml`.

You can also import an existing config to edit it, or share your configuration via the URL.
